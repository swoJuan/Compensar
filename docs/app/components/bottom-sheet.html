Bottom Sheet

Panel inferior móvil para listas, filtros y selecciones contextuales. Se ancla al borde inferior, mantiene el foco en la tarea y evita navegar a otra pantalla cuando la decisión es breve.

Estado: estable App · .NET MAUI Figma: 4489:16322 Uso: listas / filtros

1. Resumen

Cuándo usarlo

  • Para seleccionar una opción desde una lista extensa.
  • Para filtros de citas, servicios o resultados en móvil.
  • Cuando la tarea debe permanecer en el contexto actual.
  • Cuando se necesita búsqueda, scroll interno o acciones de aplicar/limpiar.

Do

Usa un sheet con handle, contenido claro y opciones táctiles de 56 px.

Don't

No lo uses para flujos largos ni para ocultar acciones críticas sin jerarquía.

Si hay más de tres pasos consecutivos, usa una pantalla dedicada.

2. Anatomía interactiva

Radio 16 px Item 56 px Padding 12-16 px
HandleIndica que el panel se puede arrastrar o cerrar.
ContenidoLista, búsqueda, chips o grupos de filtros.
AccionesAplicar y limpiar solo cuando el sheet recopila filtros.
