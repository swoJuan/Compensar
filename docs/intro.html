Guía de referencia unificada para equipos de diseño y desarrollo. Contiene los tokens, componentes y patrones que dan forma a las experiencias digitales de Compensar.

Portal Público · Drupal Zona Transaccional · Angular CSS Custom Properties

Objetivo del sistema

Este sistema de diseño centraliza las decisiones visuales y de interacción de los productos digitales de Compensar Medicina Prepagada. Su propósito es garantizar coherencia, accesibilidad y eficiencia en la implementación, tanto en el Portal Público construido con Drupal como en la Zona Transaccional desarrollada en Angular. Ambas plataformas consumen los mismos tokens y componentes base.

¿Qué vas a encontrar aquí?

Tokens de diseño

Colores, tipografía, espaciado y sombras definidos como CSS Custom Properties, sincronizados con Figma.

Tipografía & Espaciado

Escala tipográfica con Montserrat y Roboto. Grilla de 8 puntos para márgenes, paddings y gaps.

Componentes

Botones, inputs, badges y más. Cada componente incluye preview en vivo y sus estados documentados.

Código listo para usar

Snippets en CSS/Twig para Drupal y en SCSS/HTML/TS para Angular. Con botón de copia directo.

Light · Dark · Alto contraste

Todos los componentes se pueden previsualizar en los tres modos desde el toggle en el header.

Fuente única de verdad

Sincronizado con Figma. Cualquier actualización al sistema se refleja aquí primero.

¿Cómo usar este documento?
01
Importa los tokens

Incluye core.css en tu proyecto antes de los estilos propios de tu producto.

02
Consulta el componente

Busca el componente en el sidebar, revisa el preview y copia el código de tu tecnología.

03
Usa siempre tokens

Nunca uses valores hex directos. Usa var(--use-primary-default) para que los modos funcionen solos.
