Alertas

Comunican información relevante sobre el estado de una acción o del sistema. Esta página documenta la alerta contextual integrada en el contenido.

Estado: estable Versión 1.0 Web Bootstrap compatible Categoría: feedback Tipo: contextual

Contextual (Inline / Banner)

Mensaje integrado dentro de la interfaz. Se usa para validaciones en formularios, mensajes informativos y advertencias no críticas.

Características

  • checkNo bloquea la interacción.
  • checkAparece cerca del contenido relacionado.
  • checkPuede ser persistente dentro del flujo.

Ubicación

  • checkDentro de formularios.
  • checkBajo o sobre el elemento afectado.
  • checkEn bloques o secciones específicas.
  • checkSiempre visible en el flujo de lectura.

1. Resumen

Cuándo usarlo

  • checkValidaciones dentro de formularios o secciones específicas.
  • checkInformación que ayuda a completar una acción.
  • checkAdvertencias no críticas dentro del flujo.
  • checkFeedback contextual que no debe bloquear al usuario.

Do

Usa el tipo correcto y ubícalo cerca del contenido relacionado.

check_circle

Solicitud enviada

Recibirás la confirmación en tu correo.

Don’t

No dupliques mensajes ni uses alertas para decisiones que requieren confirmación.

warning

Revisa todo

Mensaje ambiguo y poco accionable.

5. Comportamiento

  • checkAparece tras una acción, evento o validación.
  • checkNo bloquea la interacción cuando es contextual.
  • checkPuede ser persistente o temporal según el patrón que lo use.
  • checkSi tiene cierre, el botón debe ser accesible por teclado.

6. Guías de contenido

  • checkUsa mensajes claros, visibles y accionables.
  • checkPrioriza claridad sobre cantidad de información.
  • checkNo dupliques mensajes para la misma acción.
  • checkUsa el tipo correcto: info, success, warning o error.

7. Accesibilidad

  • checkContraste mínimo 4.5:1.
  • checkNo depender solo del color: incluir icono y texto.
  • checkUsar `role="status"` para información y `role="alert"` para errores importantes.
  • checkEl cierre debe tener `aria-label` descriptivo.

8. Responsive

Desktop

Puede ocupar el ancho de la sección o mantener ancho contextual.

Tablet

Mantiene padding 16 px y lectura en dos líneas cuando aplique.

Mobile

Debe ajustarse a una columna sin truncar texto ni icono.
