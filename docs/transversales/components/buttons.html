Botón

Permite ejecutar acciones principales, secundarias o de apoyo dentro de la interfaz. Guía la interacción, la toma de decisiones y la jerarquía visual de cada pantalla.

Estado: estable Versión 1.0 Web Bootstrap compatible Categoría: acción

1. Resumen

Cuándo usarlo

  • checkPara ejecutar acciones principales del flujo.
  • checkPara confirmar, guardar o continuar una tarea.
  • checkPara navegar a la siguiente etapa con una acción explícita.
  • checkPara acciones de apoyo que no compitan con la acción primaria.

Do

Usa jerarquía clara y etiquetas accionables.

Don't

No uses textos ambiguos ni jerarquías confusas.

7. Accesibilidad

  • checkNavegación por teclado con Tab; activación con Enter y Space.
  • checkFocus visible en todos los estados.
  • checkContraste mínimo AA 4.5:1 para texto y controles.
  • checkBotones solo icono requieren `aria-label` descriptivo.
  • checkNo depender solo del color para comunicar estados.

8. Responsive

Desktop

Usa ancho hug content salvo acciones principales en layouts amplios.

Tablet

Mantiene altura y padding; puede agruparse en filas flexibles.

Mobile

Puede usar full width para acciones críticas y conserva área táctil mínima.
