Cards

Contenedor de contenido que agrupa información, acciones y estado en una unidad visual clara, reusable y responsive.

Estado: estable Versión 1.0 Web Bootstrap compatible Categoría: contenido

1. Resumen

Cuándo usarlo

  • Para agrupar información relacionada y sus acciones.
  • Para listar productos, servicios o resúmenes de contenido.
  • Para presentar estados de flujo con jerarquía visual.
  • Para construir layouts modulares en grilla.

Do

Incluye título claro, contenido breve y acciones accionables.

Plan integral

Resumen corto del beneficio principal.

Don’t

No sobrecargues la card con textos extensos o múltiples prioridades.

Demasiada información

Una card no debe reemplazar una página completa ni mezclar múltiples objetivos dentro del mismo bloque visual.

5. Comportamiento

  • Las variantes interactivas deben responder a hover, focus y active.
  • En móvil, la variante horizontal colapsa a vertical.
  • La acción principal debe tener prioridad visual.

6. Guías de contenido

  • Título de máximo 1 línea.
  • Descripción breve de 2 a 3 líneas.
  • Botones con verbos accionables.

7. Accesibilidad

  • Contraste mínimo AA en texto y acciones.
  • Focus visible en cards interactivas y botones internos.
  • Texto alternativo obligatorio si existe media informativa.
