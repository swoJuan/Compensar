Modal

Componente que interrumpe el flujo para presentar información importante o solicitar una decisión del usuario.

Estado: estable Versión 1.0 Web Bootstrap compatible Categoría: feedback Tipo: crítico / bloqueante

Modal (Crítico)

Este tipo bloquea la interacción con el fondo y requiere una acción explícita antes de volver al flujo.

Características

  • checkBloquea la interacción con el fondo.
  • checkSe muestra sobre overlay `#111` al 30%.
  • checkRequiere acción del usuario.
  • checkTiene alta prioridad visual.

Ubicación

  • checkCentrado en pantalla.
  • checkSobre fondo oscuro overlay.
  • checkNivel más alto de jerarquía visual.

1. Resumen

Cuándo usarlo

  • checkConfirmaciones importantes o irreversibles.
  • checkInformación crítica que exige lectura.
  • checkValidaciones que detienen el flujo.
  • checkFlujos guiados de pocos pasos.
  • closeNo usar para mensajes simples, listas largas o feedback temporal.

Do

Usa el modal cuando la decisión es necesaria para continuar.

Don’t

No lo uses para confirmaciones rápidas. Para eso usa toast.

La estructura usa clases Bootstrap y personalización `mp-modal`.

4. Tamaños ideales

    

    

      

        Pequeño · `.modal-sm`
        
300 px. Para confirmaciones cortas y mensajes de una sola acción.

      

      

        Mediano · default
        
479 px. Tamaño oficial observado en Figma y recomendado por defecto.

      

      

        Grande · `.modal-lg`
        
800 px. Para contenido guiado, tablas pequeñas o formularios breves.

      

    

  


  

    

      
5. Estados y tipos

    

    

      

        

          Info
          
Información relevante que detiene el flujo para confirmar lectura.

        

      

      

        

          Success
          
Confirmación importante después de una acción de alto impacto.

        

      

      

        

          Warning
          
Advertencia previa a una decisión sensible o irreversible.

        

      

      

        

          Error
          
Bloqueo del flujo por error que requiere corrección o salida.

        

      

    

  


  

    

      
6. Comportamiento

    

    

      

        

          open_in_new
          Apertura
          
Se abre después de una acción y mueve el foco al modal.

        

      

      

        

          block
          Bloqueo
          
El overlay bloquea el contenido de fondo mientras el modal está activo.

        

      

      

        

          keyboard
          Teclado
          
ESC cierra el modal y Tab mantiene el foco dentro del contenedor.

        

      

      

        

          close
          Cierre
          
Permite cerrar con X, acción secundaria, botón principal cuando aplique o ESC.

        

      

    

  


  

    

      
7. Guías de contenido

    

    

      

        
Do

        
    
          
  • checkUsa títulos directos que expliquen el problema o decisión.
    • 
          
  • checkRedacta mensajes breves y accionables.
    • 
          
  • checkUsa una sola acción primaria.
    • 
        

      

      

        
Don’t

        
    
          
  • closeNo incluyas textos largos o listas extensas.
    • 
          
  • closeNo uses etiquetas ambiguas como “Aceptar” si la acción es irreversible.
    • 
          
  • closeNo combines varias decisiones en el mismo modal.
    • 
        

      

    

  


  

    

      
8. Accesibilidad

    

    

      

        
    
          
  • checkUsar `role="dialog"` y `aria-modal="true"`.
    • 
          
  • checkConectar título con `aria-labelledby`.
    • 
          
  • checkConectar mensaje con `aria-describedby`.
    • 
          
  • checkDevolver el foco al botón que abrió el modal.
    • 
        

      

      

        
    
          
  • checkFocus visible en cierre y acciones.
    • 
          
  • checkContraste mínimo AA.
    • 
          
  • checkNo depender solo del color para comunicar tipo.
    • 
          
  • checkNo abrir múltiples modales simultáneamente.
    •
