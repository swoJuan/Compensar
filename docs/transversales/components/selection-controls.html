Checkbox / Radio / Switch

Permiten al usuario tomar decisiones dentro de la interfaz: selección múltiple, selección única y activación inmediata de opciones binarias.

Estado: estable Versión 1.0 Web Bootstrap compatible Categoría: selección

1. Resumen

Cuándo usarlo

  • checkCheckbox: cuando se permiten varias opciones.
  • checkRadio: cuando solo se permite una opción por grupo.
  • checkSwitch: cuando el cambio es inmediato y binario.
  • checkCuando la decisión necesita label visible y accesible.

Do

Usa el control que corresponda al tipo de decisión.

Don't

No uses switch para decisiones que requieren guardar o confirmar.

5. Comportamiento

  • checkCheckbox permite múltiples selecciones y puede marcarse o desmarcarse.
  • checkRadio solo permite una selección activa por grupo.
  • checkSwitch alterna entre dos estados y aplica el cambio de inmediato.
  • checkTodos deben responder a click, Enter y Space.

6. Guías de contenido

  • checkUsa labels breves, claros y accionables.
  • checkEvita preguntas ambiguas o dobles negaciones.
  • checkEl texto de apoyo debe explicar error, requisito o consecuencia.
  • checkEn switch, el label debe describir qué se activa o desactiva.

7. Accesibilidad

  • checkÁrea mínima: 44 x 44 px.
  • checkLabel asociado al control mediante estructura de label/input.
  • checkFocus visible obligatorio.
  • checkNo depender solo del color para error o selección.
  • checkGrupos radio deben usar `name` compartido.

8. Responsive

Desktop

Se agrupan en listas o columnas según el formulario.

Tablet

Mantienen área táctil y separación entre opciones.

Mobile

Usar una opción por fila cuando haya labels largos.
