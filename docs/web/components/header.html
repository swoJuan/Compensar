Header Web / Drupal

Organiza la navegación principal del portal público y la zona transaccional: marca, búsqueda, acciones clave, menú horizontal y adaptación responsive.

Estado: estable Versión 1.0 Web / Drupal Categoría: navegación Figma: 4705:5362

1. Resumen

Cuándo usarlo

  • Como navegación global del portal público Drupal.
  • Cuando el usuario debe explorar categorías, servicios y accesos de negocio.
  • Para zona transaccional con menú de módulos y acceso rápido al dashboard.
  • Cuando el responsive debe pasar a drawer o menú lateral sin perder acciones clave.

Do

Prioriza categorías cortas, buscador visible y una acción principal clara.

Afíliate Buscar servicios

Don't

No satures el primer nivel con enlaces largos o acciones duplicadas.

6. Responsive y comportamiento

    

    

      
Desktop
Mantiene navegación horizontal, buscador visible, CTA principal y submenús agrupados por categoría.

      
Mobile
Pasa a drawer o menú lateral, conserva acciones de negocio y permite cerrar con X, overlay o tecla Escape.

      
ZT
El menú lateral agrupa módulos transaccionales; el header superior conserva identidad, búsqueda y sesión.

      
Accesibilidad
Usa nav, labels claros, foco visible y estados aria-expanded cuando haya submenús o drawer.
