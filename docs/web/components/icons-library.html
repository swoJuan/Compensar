Accesibilidad

Los iconos deben complementar el contenido, no reemplazarlo.

Iconos decorativos
  • Usar aria-hidden="true"
  • No añaden información semántica
  • Acompañan texto visible
Iconos interactivos
  • Usar aria-label descriptivo
  • El label debe describir la acción
  • Área táctil mínima: 44×44px
Buenas prácticas
  • No usar iconos como única información
  • Incluir etiquetas o texto cuando la acción no sea evidente
  • Mantener contraste adecuado entre icono y fondo
Evitar
  • Iconos sin texto en acciones no obvias
  • Mezcla de estilos (outline + filled)
  • Tamaños fuera de la escala del sistema
