Input

Campos de texto para captura de información. Soporta texto, email, número, contraseña, textarea y select con estados interactivos completos.

Estados principales
Ingresa tu nombre como en tu documento
mail
✓ Correo válido
✕ Formato inválido. Ej: AF-12345

Estados

Texto de ayuda
Default
Estado de reposo. Borde neutro, placeholder visible, campo editable.
Texto de ayuda
Focus
Al hacer clic o tab. Borde naranja marca y ring de 3 px para accesibilidad.
Texto de ayuda
Filled
Campo con valor. Borde levemente más oscuro para diferenciar de vacío.
✕ Mensaje de error
Error
Borde rojo + ring de error. El mensaje debajo describe la corrección necesaria.
✓ Valor confirmado
Success
Validación superada. Helper en verde confirma el dato ingresado correctamente.
Campo deshabilitado
Disabled
No interactivo. Fondo gris, cursor no-allowed, no recibe focus ni validaciones.

Tipos

Texto simple
Variante base. Sin íconos, sin prefijos. Ideal para nombres, documentos, campos alfanuméricos.
Usa cuando: la etiqueta ya explica el contenido esperado.
search
Con ícono izquierdo
Ícono decorativo que refuerza el tipo de dato esperado (correo, búsqueda, teléfono).
Usa cuando: el contexto visual ayuda a entender el campo rápidamente.
visibility
Mín. 8 caracteres
Con ícono derecho interactivo
Ícono accionable (mostrar/ocultar contraseña, limpiar campo). Debe tener aria-label.
Usa cuando: hay una acción disponible relacionada con el campo.
attach_money info
En pesos colombianos
Con íconos dobles
Ícono contextual izquierdo + acción o información a la derecha.
Usa cuando: necesitas ambos contexto visual y acción secundaria.
Máximo 500 caracteres
Textarea
Área de texto redimensionable para contenido extenso.
Usa cuando: el usuario necesita ingresar más de una línea de texto.
expand_more
Select
Lista desplegable nativa con ícono de flecha. Misma apariencia que el input de texto.
Usa cuando: hay un conjunto fijo y reducido de opciones (< 7 ítems).

// mp-input.component.ts
import { Component, Input, OnInit, Self, Optional } from '@angular/core';
import { CommonModule } from '@angular/common';
import { ReactiveFormsModule, ControlValueAccessor,
         NgControl, AbstractControl } from '@angular/forms';

@Component({
  selector: 'mp-input',
  standalone: true,
  imports: [CommonModule, ReactiveFormsModule],
  template: `
<div class="mp-input-group">
  <label *ngIf="label" class="mp-input-label" [for]="inputId">
    {{ label }}
    <span *ngIf="required" class="mp-input-required" aria-hidden="true">*</span>
  </label>

  <div class="mp-input-wrapper">

    <!-- Textarea -->
    <textarea *ngIf="tipo === 'textarea'"
      [id]="inputId"
      class="mp-input-field mp-textarea"
      [class.error]="hasError"
      [class.filled]="hasValue"
      [rows]="rows"
      [placeholder]="placeholder"
      [disabled]="isDisabled"
      [attr.aria-describedby]="helperId"
      [attr.aria-invalid]="hasError || null"
      (input)="onInput($event)"
      (blur)="onTouched()"
    ></textarea>

    <!-- Select -->
    <ng-container *ngIf="tipo === 'select'">
      <select
        [id]="inputId"
        class="mp-input-field mp-select"
        [class.error]="hasError"
        [class.filled]="hasValue"
        [disabled]="isDisabled"
        [attr.aria-describedby]="helperId"
        [attr.aria-invalid]="hasError || null"
        (change)="onInput($event)"
        (blur)="onTouched()"
      >
        <option value="" disabled [selected]="!value">{{ placeholder }}</option>
        <option *ngFor="let opt of options" [value]="opt.value">
          {{ opt.label }}
        </option>
      </select>
      <span class="material-symbols-rounded mp-input-icon mp-input-icon--right" aria-hidden="true">expand_more</span>
    </ng-container>

    <!-- Text / Email / Password / Number -->
    <ng-container *ngIf="tipo !== 'textarea' && tipo !== 'select'">
      <span *ngIf="iconLeft" class="material-symbols-rounded mp-input-icon mp-input-icon--left" aria-hidden="true">
        {{ iconLeft }}
      </span>
      <input
        [id]="inputId"
        class="mp-input-field"
        [class.has-icon-left]="iconLeft"
        [class.has-icon-right]="iconRight"
        [class.error]="hasError"
        [class.filled]="hasValue"
        [type]="currentType"
        [placeholder]="placeholder"
        [disabled]="isDisabled"
        [attr.aria-describedby]="helperId"
        [attr.aria-invalid]="hasError || null"
        (input)="onInput($event)"
        (blur)="onTouched()"
      >
      <button *ngIf="iconRight && iconRightAction"
        type="button"
        class="mp-input-icon mp-input-icon--right interactive"
        [attr.aria-label]="iconRightLabel"
        (click)="onIconRightClick()"
      >
        <span class="material-symbols-rounded" aria-hidden="true">{{ currentIconRight }}</span>
      </button>
      <span *ngIf="iconRight && !iconRightAction"
        class="material-symbols-rounded mp-input-icon mp-input-icon--right" aria-hidden="true">
        {{ iconRight }}
      </span>
    </ng-container>

  </div>

  <span *ngIf="helperText || hasError" [id]="helperId"
    class="mp-input-helper"
    [class.error]="hasError"
    [class.success]="!hasError && showSuccess">
    {{ hasError ? errorMessage : helperText }}
  </span>
</div>
  `
})
export class MpInputComponent implements ControlValueAccessor, OnInit {
  @Input() tipo: 'text' | 'email' | 'password' | 'number' | 'search' | 'textarea' | 'select' = 'text';
  @Input() label = '';
  @Input() placeholder = '';
  @Input() helperText = '';
  @Input() iconLeft?: string;
  @Input() iconRight?: string;
  @Input() iconRightAction = false;
  @Input() iconRightLabel = 'Acción';
  @Input() required = false;
  @Input() rows = 3;
  @Input() options: Array<{ value: string; label: string }> = [];
  @Input() showSuccess = false;

  value = '';
  isDisabled = false;
  isPasswordVisible = false;
  inputId = `mp-input-` + Math.random().toString(36).slice(2);
  helperId = `mp-input-help-` + Math.random().toString(36).slice(2);

  onChange = (_: any) => {};
  onTouched = () => {};

  constructor(@Self() @Optional() public ngControl: NgControl) {
    if (ngControl) ngControl.valueAccessor = this;
  }

  get hasValue() { return !!this.value; }
  get hasError() { return this.ngControl?.invalid && this.ngControl?.touched; }
  get errorMessage() { return Object.values(this.ngControl?.errors ?? {})[0] ?? 'Campo inválido'; }
  get currentType() { return this.tipo === 'password' ? (this.isPasswordVisible ? 'text' : 'password') : this.tipo; }
  get currentIconRight() { return this.tipo === 'password' ? (this.isPasswordVisible ? 'visibility_off' : 'visibility') : this.iconRight; }

  writeValue(v: any) { this.value = v ?? ''; }
  registerOnChange(fn: any) { this.onChange = fn; }
  registerOnTouched(fn: any) { this.onTouched = fn; }
  setDisabledState(d: boolean) { this.isDisabled = d; }

  onInput(e: Event) {
    const el = e.target as HTMLInputElement;
    this.value = el.value;
    this.onChange(this.value);
  }

  onIconRightClick() {
    if (this.tipo === 'password') this.isPasswordVisible = !this.isPasswordVisible;
  }

  ngOnInit() {}
}

API del componente

Propiedad Tipo Default Descripción
tipo 'text' | 'email' | 'password' | 'number' | 'search' | 'textarea' | 'select' 'text' Variante del campo. Define el tipo de input HTML o el elemento a renderizar.
label string '' Texto de la etiqueta asociada al campo.
placeholder string '' Texto de ejemplo cuando el campo está vacío.
helperText string '' Texto de ayuda bajo el campo. Si hay error, se reemplaza por el mensaje de error.
iconLeft string — Nombre del ícono Material Symbols a mostrar a la izquierda (decorativo).
iconRight string — Nombre del ícono a mostrar a la derecha. Combinar con iconRightAction para hacerlo interactivo.
iconRightAction boolean false Si es true, el ícono derecho se renderiza como botón. En campos password, alterna visibilidad automáticamente.
required boolean false Agrega asterisco visual, atributo required y aria-required="true".
rows number 3 Número de filas visibles. Solo aplica cuando tipo="textarea".
options Array<{value,label}> [] Opciones del select. Solo aplica cuando tipo="select".
showSuccess boolean false Muestra el helper en verde cuando el campo es válido y no tiene error.
formControl FormControl — Control reactivo de Angular. El error se infiere automáticamente desde ngControl.errors.

Accesibilidad

🏷️
Label explícito
Cada campo tiene un <label for="…"> asociado. Nunca uses solo el placeholder como único identificador visual.
🔴
Errores accesibles
aria-invalid="true" + aria-describedby conectan el mensaje de error al campo para lectores de pantalla.
🔑
Campos requeridos
El asterisco (*) es visual y aria-hidden="true". El atributo nativo required + aria-required="true" comunican la obligatoriedad a AT.
👁️
Íconos interactivos
Los íconos de acción (ver contraseña, limpiar campo) se renderizan como <button> con aria-label descriptivo. Los decorativos llevan aria-hidden="true".
