Contenedores de layout

MAUI ofrece 5 contenedores principales. Elegir el correcto reduce código y mejora el rendimiento.

Grid Más versátil

Filas y columnas. Permite alineación precisa, spans y superposición de elementos.

Formularios Cards de detalle Pantallas complejas
<Grid ColumnDefinitions="*,*">
VerticalStackLayout

Apila elementos verticalmente con espaciado uniforme. Más eficiente que StackLayout.

Listas de items Formularios simples
<VerticalStackLayout Spacing="16">
HorizontalStackLayout

Apila elementos en fila. Ideal para barras de iconos, chips y filas de botones.

Toolbars Chips / Tags
<HorizontalStackLayout Spacing="8">
FlexLayout

Equivalente a CSS Flexbox. Soporta Wrap, justificación y alineación flexibles.

Grids de fotos Tags con wrap
<FlexLayout Wrap="Wrap">
AbsoluteLayout

Posicionamiento absoluto dentro de un contenedor. Para overlays y elementos flotantes.

Badges FAB (botón flotante)
<AbsoluteLayout>

Grid — el layout principal

El contenedor más usado en la app. Dominar Grid resuelve el 80 % de los layouts.

Shell Navigation

Shell es la estructura de navegación de la app. Define la jerarquía de pantallas, tabs y menú lateral de forma declarativa.

tab
Tab Bar Navegación principal — máx. 5 tabs
  • Inicio, Citas, Mi Plan, Historial
  • Tab activo: ícono filled + color acento
  • iOS: TabBar nativo · Android: BottomNavigationView
menu
Flyout (menú lateral) Menú hamburguesa — secciones secundarias
  • Configuración, Soporte, Cerrar sesión
  • Se combina con Tab Bar para híbridos
  • Usar FlyoutBehavior="Flyout"
<!-- AppShell.xaml -->
<Shell
    x:Class="Compensar.AppShell"
    xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
    Shell.TabBarBackgroundColor="{StaticResource ui-surface}"
    Shell.TabBarForegroundColor="{StaticResource product-accent-100}"
    Shell.TabBarUnselectedColor="{StaticResource ui-text-muted}">

    <TabBar>
        <Tab Title="Inicio" Icon="home.svg">
            <ShellContent
                ContentTemplate="{DataTemplate local:HomePage}" />
        </Tab>
        <Tab Title="Mi Plan" Icon="shield.svg">
            <ShellContent
                ContentTemplate="{DataTemplate local:PlanPage}" />
        </Tab>
        <Tab Title="Citas" Icon="calendar.svg">
            <ShellContent
                ContentTemplate="{DataTemplate local:AppointmentsPage}" />
        </Tab>
    </TabBar>

</Shell>
// Registrar rutas en MauiProgram.cs o AppShell.xaml.cs
public AppShell()
{
    InitializeComponent();

    // Registrar rutas para navegación por URI
    Routing.RegisterRoute("detalle-plan", typeof(PlanDetailPage));
    Routing.RegisterRoute("reservar-cita", typeof(BookAppointmentPage));
    Routing.RegisterRoute("resultados",    typeof(ResultsPage));
}

// Navegar desde cualquier página
await Shell.Current.GoToAsync("detalle-plan");

// Navegar con parámetros
await Shell.Current.GoToAsync(
    $"detalle-plan?planId={plan.Id}");

// Navegar atrás
await Shell.Current.GoToAsync("..");

Reglas clave

✓

Usar Grid para layouts de 2+ dimensiones y VerticalStackLayout para listas simples

✗

No anidar múltiples StackLayout para crear grids — usar Grid directamente

✓

Envolver contenido largo en ScrollView antes de VerticalStackLayout

✗

No poner ScrollView dentro de CollectionView — causa scroll conflictivo

✓

Siempre respetar safe areas — usar Shell para que las maneje automáticamente

✗

No usar valores de padding/margin hardcoded para safe areas — cambian por modelo de iPhone

✓

Targets táctiles mínimos de 44×44 pt (iOS) / 48×48 dp (Android)

✗

No usar AbsoluteLayout con coordenadas fijas para el layout principal de pantalla
