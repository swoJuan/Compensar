# Nara – paquete de conocimiento para Copilot

Este paquete contiene los archivos recomendados para alimentar a **Nara – QA Compensar**, una asistente de revisión QA visual para interfaces del sistema de diseño Compensar.

Sube estos archivos como conocimiento del agente:

6. `06-formato-respuesta-nara.md`

## Configuración sugerida en Copilot

- **Search all websites:** OFF
- **Only use specified sources:** ON
- **Reference org chart and profile info:** OFF
- **Create images:** OFF
- **Create documents, charts, and code:** ON

## Para que Nara mejore con el tiempo

Mantén vivo el archivo `07-aprendizajes-qa-template.md` en SharePoint o en la fuente de conocimiento conectada. Cada vez que QA, diseño o desarrollo valide una decisión, agrega una fila nueva. Ese documento será la memoria curada de Nara.

Nara no aprende sola de forma automática. Aprende cuando el equipo convierte decisiones reales en reglas o ejemplos validados y los carga como conocimiento.
