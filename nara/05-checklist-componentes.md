# Checklist de componentes para Nara

## Botones

- Texto claro, corto y accionable.
- Escritura consistente con el sistema.
- Jerarquía clara entre primario y secundario.
- Color alineado visualmente con la variante.
- Padding proporcional.
- Contenido centrado.
- Ícono alineado y espaciado si aplica.
- Estados hover, focus, disabled o error distinguibles si aplica.
- No se percibe comprimido, desbalanceado o desalineado.

## Inputs y formularios

- Label visible y claro.
- Placeholder no reemplaza el label.
- Ayuda o error comprensible cuando aplica.
- Estado focus visible.
- Estado error no depende solo del color.
- Alineación y espaciado consistentes.
- Tamaño táctil adecuado en mobile.

## Cards

- Jerarquía clara entre imagen, título, descripción y acciones.
- Padding interno consistente.
- Borde/radio/sombra alineados al patrón.
- Imagen o placeholder consistente entre cards del mismo tipo.
- Acciones claras y bien ubicadas.
- No hay saltos visuales innecesarios por diferencias de altura.

## Alertas

- Variante coherente con el mensaje: info, éxito, advertencia o error.
- Ícono, color y texto refuerzan el estado.
- No se comunica solo con color.
- Texto breve y accionable.
- Contraste suficiente.

## Modales y overlays

- Título claro.
- Mensaje breve.
- Acción principal y secundaria diferenciadas.
- Foco y cierre claros.
- No se usa modal cuando bastaría alerta contextual o toast.

## Toasts

- Mensaje corto.
- Ancho adecuado.
- Ubicación esperada.
- No bloquea contenido crítico.
- Variante coherente con estado.

## Tablas

- Encabezados claros.
- Alineación consistente.
- Estados hover/selected distinguibles.
- Responsive con scroll o adaptación.
- No saturar columnas en mobile.

## Tabs, chips y filtros

- Estado activo claro.
- Labels cortos.
- Espaciado consistente.
- No depender solo del color para selección.
- Filtros activos visibles y removibles cuando aplique.

## Breadcrumbs y navegación

- Ruta clara.
- Separadores consistentes.
- Estado actual identificable.
- Accesible por teclado y lector cuando aplique.
