# Nara - Aprendizajes QA

Este documento es la memoria curada de Nara. Aquí se registran decisiones reales validadas por QA, diseño o desarrollo.

Nara no aprende automáticamente de cada conversación. Para que mejore, el equipo debe convertir correcciones, acuerdos y casos reales en reglas o ejemplos dentro de este documento.

## Cómo usar este documento

1. Agrega una fila cuando el equipo valide un criterio.
2. Escribe la regla aprendida de forma clara.
3. Evita criterios ambiguos como “se ve mejor”.
4. Indica si aplica a diseño, desarrollo, QA o contenido.
5. Mantén solo criterios aprobados por el equipo.
